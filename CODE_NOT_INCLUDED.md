# Code not included

This repository is the public project record for Queen: its agreement, walkthrough, evidence and review boundaries. It does not contain Queen's source code. The documented terminal route is evidence supplied with the project, not an executable included here.

The project plan says the code will open during the judges' review period under the review-only license. That license permits reading and cloning to evaluate. Check [the license](./LICENSE) for the exact terms before relying on that permission. No code or implementation is offered by this document.

When the source becomes available, a reviewer can compare the implementation with the agreement, run `npm test` in the project directory and compare the outcomes with [Evidence](./docs/EVIDENCE.md). The supplied run of 2026-10-09 reports 45 tests, 45 passing, none skipped; the kernel re-pin to Vespi 0.1.5 is done, so the source review should compare against the reference `docs/suite-2026-10-09.txt`.
