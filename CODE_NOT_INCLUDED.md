# Code not included

This repository is the public project record for Queen: its agreement, walkthrough, evidence and review boundaries. It does not contain Queen's source code. The documented terminal route is evidence supplied with the project, not an executable included here.

The project plan says the code will open during the judges' review period under the review-only license. That license permits reading and cloning to evaluate. Check [the license](./LICENSE) for the exact terms before relying on that permission. No code or implementation is offered by this document.

When the source becomes available, a reviewer can compare the implementation with the agreement, run `npm test` in the project directory and compare the outcomes with [Evidence](./docs/EVIDENCE.md). The supplied run currently reports 42 passing tests out of 45, with three kernel digest pin checks failing. The kernel re-pin remains pending, so the source review should account for that status.

# Código no incluido

Este repositorio es el registro público del proyecto Queen: contiene su acuerdo, recorrido, evidencia y límites de revisión. No incluye el código fuente de Queen. El recorrido de terminal documentado es evidencia suministrada con el proyecto, no un programa ejecutable incluido aquí.

El plan del proyecto dice que el código se abrirá durante el periodo de revisión de los jueces bajo la licencia de solo revisión. Esa licencia permite leer y clonar para evaluar. Consulta [la licencia](./LICENSE) para conocer sus términos exactos antes de apoyarte en ese permiso. Este documento no ofrece código ni una implementación.

Cuando el código esté disponible, quien lo revise podrá comparar la implementación con el acuerdo, ejecutar `npm test` desde el directorio del proyecto y comparar los resultados con [Evidencia](./docs/EVIDENCE.md). La ejecución suministrada informa actualmente 42 pruebas aprobadas de 45, con tres fallas en las comprobaciones de fijación por digest del kernel. La nueva fijación sigue pendiente, así que la revisión del código debe considerar ese estado.
